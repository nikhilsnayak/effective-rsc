# Security Policy

## Supported versions

Security fixes are provided only for the latest published release.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Instead, use
[GitHub's private vulnerability reporting](https://github.com/nikhilsnayak/effective-rsc/security/advisories/new).

Include the affected version, expected impact, reproduction steps or a proof of concept, and any
suggested remediation.
